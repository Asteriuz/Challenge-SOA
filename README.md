## Critérios de Avaliação

Integração por Web Services (50%)

- [x] Desenho de arquitetura contendo os componentes que pretendem usar (10%)
- [x] Implementação de APIs RESTful ou SOAP para comunicação entre sistemas (20%)
- [x] Uso adequado de métodos HTTP (10%)
- [x] Documentação das APIs com README ou Swagger como um contrato com os endpoints (10%)

Arquitetura Orientada a Serviços (SOA) (20%)

- [x] Organização modular baseada em serviços independentes e reutilizáveis (10%)
- [x] Separação clara entre camadas de apresentação, serviço e dados (10%)

Padrões e Boas Práticas (15%)

- [x] Adoção de padrões como REST, SOAP, JSON, XML, WSDL (8%)
- [x] Tratamento adequado de erros e exceções nos serviços (7%)

Conexão com banco de dados (15%)

- [x] Dependências e configurações para conexão (8%)
- [x] Controle de migrações (7%)
